# شركة ركن الحراملة العقارية | Rukn Al-Haramala Real Estate

منصة عقارية رقمية حديثة وفاخرة لـ **شركة ركن الحراملة العقارية**، متخصصة في طرح وتسويق الأراضي والمخططات الاستثمارية السكنية والتجارية في المملكة العربية السعودية، مع دعم مباشر للربط اللحظي مع جداول بيانات Google Sheets.

---

## 🌟 المميزات الرئيسية (Key Features)

- **هوية بصرية فاخرة (Luxury Real Estate Theme):**
  - ألوان داكنة ملكية (فحم داكن `#121212`, أسطح مرتفعة `#1A1A1A` و `#202020`).
  - لمسات وتدرجات الذهب المعدني (`#C5A059`, `#DFBE7B`).
  - خط عربي متميز عبر **IBM Plex Sans Arabic** ودعم أصيل لاتجاه القراءة من اليمين لليسار (`dir="rtl"`).

- **تكامل حي ومباشر مع Google Sheets (100% Live Data Engine):**
  - جلب وتحليل فوري لبيانات العروض العقارية المنشورة عبر Google Sheets CSV.
  - مطابقة مرنة للحقول تدعم كلاً من المسميات العربية والإنجليزية:
    `id`, `title`, `type`, `district`, `area`, `streets`, `dimensions`, `price`, `status`, `map_url`, `image_url`.
  - معالجة تلقائية لروابط Google Drive وتحويلها إلى روابط عرض مباشر فائقة السرعة.
  - إخفاء ديناميكي للبيانات الاختيارية غير المعبأة لضمان بطاقات نظيفة بدون فراغات أو نصوص مصطنعة.

- **فلاتر تفاعلية ذكية (Dynamic Filters):**
  - توليد أزرار الفلترة تلقائياً بناءً على القيم الفعلية الموجودة في عمود `type` في جدول قوقل.
  - مفتاح تبديل فوري لخيار `إخفاء المباع`.
  - شريط بحث لحظي باسم الحي، كود العقار، أو العنوان.

- **مؤثرات حركية فائقة الجودة (Powered by MengTo Skills):**
  - **GSAP & ScrollTrigger:** ظهور تدريجي منسق للواجهة (Hero Entrance) وكشف متحرك للعناصر عند التمرير.
  - **Reveal Hover Effect:** كشاف ضوئي ذهبي ناعم يتعقب مؤشر الماوس بدقة على البطاقات والصور عبر `requestAnimationFrame`.
  - **Liquid Metal Border:** إطار ذهبي معدني متوهج دوّار بتدرجات `conic-gradient` يعكس لمسات الفخامة على بطاقات العقارات.

- **تحويل الطلبات إلى واتساب مباشرة (WhatsApp Direct Leads):**
  - زر استفسار لكل عقار يولد رسالة واتساب معبأة مسبقاً بكود واسم العقار.
  - نموذج طلب مباشر (شراء أرض / تسويق أرض / استفسار عام) يرسل كافة تفاصيل العميل مباشرة إلى واتساب الشركة.

## 🚀 التشغيل والنشر (Deployment)

المشروع مصمم ليعمل بدون أي أدوات بناء (Zero-Build Static Architecture)، ويمكن تشغيله أو نشره مباشرة عبر:

1. **التشغيل المحلي:**
   - فتح ملف `index.html` في أي متصفح حديث، أو تشغيل خادم محلي مثل `Live Server` أو `npx serve`.

2. **النشر السحابي المجاني:**
   - **GitHub Pages:** من إعدادات المستودع (Settings -> Pages -> Deploy from branch `main` / `master`).
   - **Vercel / Netlify:** ربط المستودع مباشرة والنشر التلقائي بنقرة واحدة.
